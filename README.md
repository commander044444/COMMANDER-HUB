# COMMANDER HUB

**داشبورد شخصی مدرن، قدرتمند و کاملاً کلاینت‌ساید**

COMMANDER HUB یک داشبورد شخصی کامل است که با HTML5، CSS3 و Vanilla JavaScript ساخته شده و بدون نیاز به سرور یا بیلد سیستم روی GitHub Pages و به‌صورت محلی کار می‌کند.

---

## ویژگی‌ها

- **داشبورد قابل سفارشی‌سازی** با ویجت‌های متنوع (ساعت، آب‌وهوا، کارها، یادداشت، رمزارز، اخبار و …)
- **چند فضای کاری** (شخصی، برنامه‌نویسی، بازی، مالی، مطالعه)
- **پشتیبانی کامل فارسی و انگلیسی** با RTL/LTR و تغییر زبان بدون رفرش
- **تم‌های تیره/روشن و چند تم رنگی** + رنگ تأکیدی، تراکم، گوشه‌ها و اندازه فونت
- **قفل اختیاری برنامه** (PIN/رمز) با قفل خودکار پس از عدم فعالیت
- **بازار رمزارز زنده** از CoinGecko
- **پورتفولیو دستی** با محاسبه سود/زیان بر اساس قیمت‌های واقعی
- **یادداشت‌ها** با سنجاق، برچسب، جستجو و ذخیره خودکار
- **مدیریت کارها و اهداف روزانه**
- **تقویم و رویدادها**
- **اخبار** از RSS (با پروکسی عمومی)
- **آب‌وهوا** از Open-Meteo (بدون کلید API)
- **جستجوی سراسری و پالت فرمان** (Ctrl+K)
- **پشتیبان‌گیری و بازیابی** JSON
- **PWA** قابل نصب با پشتیبانی آفلاین از شل برنامه
- **ذخیره‌سازی محلی** (localStorage) — داده‌ها از مرورگر شما خارج نمی‌شوند

## نحوه اجرا با VS Code Live Server

1. پوشه `COMMANDER-HUB` را در VS Code باز کنید.
2. افزونه **Live Server** را نصب کنید.
3. روی `index.html` راست‌کلیک کرده و **Open with Live Server** را انتخاب کنید.
4. داشبورد در مرورگر باز می‌شود.

> نکته: برای عملکرد کامل Service Worker و PWA، بهتر است از یک سرور محلی (نه `file://`) استفاده کنید.

## آپلود روی GitHub و فعال‌سازی GitHub Pages

1. یک مخزن جدید در GitHub بسازید (مثلاً `COMMANDER-HUB`).
2. محتویات پوشه `COMMANDER-HUB` را داخل مخزن قرار دهید (نه خود پوشه ریشه).
3. به **Settings → Pages** بروید.
4. در بخش **Source** گزینه **Deploy from a branch** را انتخاب کنید.
5. Branch را `main` (یا `master`) و پوشه را `/ (root)` قرار دهید و Save کنید.
6. پس از چند دقیقه آدرس زیر در دسترس خواهد بود:
   ```
   https://USERNAME.github.io/COMMANDER-HUB/
   ```

### مسیرها و سازگاری

- همه مسیرها نسبی هستند (`./css/...`, `./js/...`).
- Service Worker و Manifest برای زیردامنه GitHub Pages طراحی شده‌اند.
- نیازی به تنظیم `base` یا بیلد نیست.

## سازگاری مرورگر

- Chrome / Edge (توصیه‌شده)
- Firefox
- Safari (جدید)
- مرورگرهای موبایل مدرن

ویژگی‌هایی مثل Web Crypto، Service Worker و Geolocation در مرورگرهای قدیمی ممکن است محدود باشند. برنامه بدون آن‌ها نیز بخش‌های اصلی را نمایش می‌دهد.

## ذخیره‌سازی محلی

- تمام داده‌ها (یادداشت، کارها، تنظیمات، پورتفولیو، فضاهای کاری و …) در **localStorage** مرورگر ذخیره می‌شوند.
- پاک کردن داده‌های مرورگر یا استفاده از حالت ناشناس باعث حذف اطلاعات می‌شود.
- از بخش **تنظیمات → پشتیبان‌گیری** خروجی JSON بگیرید و نگه دارید.

---

## پشتیبان‌گیری و بازیابی

1. به **تنظیمات** بروید.
2. **خروجی JSON** را بزنید تا فایل پشتیبان دانلود شود.
3. برای بازیابی، **وارد کردن** را بزنید و فایل را انتخاب کنید.
4. قبل از بازنویسی داده‌ها تأیید گرفته می‌شود.

## محدودیت‌های APIهای خارجی

| سرویس       | منبع          | نیاز به کلید | توضیحات                          |
|-------------|---------------|--------------|----------------------------------|
| رمزارز      | CoinGecko     | خیر          | محدودیت نرخ درخواست دارد         |
| آب‌وهوا     | Open-Meteo    | خیر          | رایگان و بدون کلید               |
| اخبار       | RSS + پروکسی  | خیر          | ممکن است گاهی در دسترس نباشد     |

در صورت قطع API، ویجت مربوطه پیام خطا نشان می‌دهد و بقیه داشبورد کار می‌کند. داده جعلی نمایش داده نمی‌شود.

## حریم خصوصی و امنیت

- هیچ داده‌ای به سرور شخص ثالث ارسال نمی‌شود مگر برای درخواست‌های صریح (قیمت، آب‌وهوا، اخبار).
- **قفل برنامه** فقط یک قفل سمت کلاینت است و امنیت قوی ندارد. اطلاعات بسیار حساس را در این اپ ذخیره نکنید.
- رمز عبور به صورت هش (SHA-256 در صورت پشتیبانی) ذخیره می‌شود و به صورت متن ساده نگه داشته نمی‌شود.
